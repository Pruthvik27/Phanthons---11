## 📌 Problem Statement

In hospitals, delays in communicating medicine and supply requests from patient rooms to the pharmacy can significantly impact efficiency, especially during busy or emergency situations. Many small and medium hospitals still rely on manual processes, which increases workload and slows down response time.

There is a lack of automated systems to efficiently handle and communicate these requests in real time.

To address this issue, this project proposes a low-cost autonomous robot capable of navigating hospital wards, detecting requests from individual rooms, and communicating the total requests directly to the pharmacy. This enables faster response, reduces human effort, and improves overall operational efficiency in healthcare environments.

📄 Detailed problem statement available in [`docs/problem-statement.md`](docs/problem-statement.md)

---

## 💡 Solution

We developed an **autonomous hospital bot** that navigates through predefined paths inside hospital wards. The bot intelligently detects request signals from each room, counts them, and delivers the information directly to the pharmacy.

This system minimizes manual communication, speeds up response time, and ensures reliable operation in critical environments.

---

## ⚙️ Expected Output

* 🤖 Bot follows a predefined path
* 🛑 Stops at each room
* 📡 Detects presence/absence of requests
* 🔢 Counts total requests accurately
* 🏥 Reaches pharmacy station

### 📊 Reporting System

* 💡 LED blinks = number of requests
* 🔔 Buzzer beeps = number of rooms
